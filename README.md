# 🎬 iCinema – Movie Browsing and Booking Website

## 📖 About the Project

iCinema is a movie browsing and booking website developed as part of my HND Computing and Software Development coursework.

The project aims to provide users with a simple, responsive and user-friendly interface for discovering movies, exploring cinemas, viewing screening times and progressing through a cinema booking journey.

The website is being developed using HTML, CSS, Bootstrap and PHP, with a focus on responsive design, clear navigation and reusable website components.

## ✨ Features

### ✅ Main Website Pages

- 🏠 **Home Page** – The main landing page for the website.
- 🎬 **Movies Page** – Allows users to browse available movies.
- 🎞️ **Movie Detail Page** – Displays information about an individual movie.
- 🍿 **Cinemas Page** – Provides information about available cinemas.
- 🕒 **Showtimes Page** – Displays movie screening times.
- 💺 **Seats Page** – Provides an interface for selecting seats.
- 💳 **Checkout Page** – Presents the checkout stage of the booking process.
- ✅ **Booking Confirmation Page** – Displays booking confirmation information.

### 🚧 Planned Features

- 👤 **Membership Page** – A planned page for membership information and related features.
- 🛟 **Support Page** – A planned page for customer support and assistance.
- 👷 **Admin Page** - A planned page for iCinema workers to add move movies to the database.
*Note: The Membership, Support and Admin pages have not yet been implemented and are planned for future development.*

## 🛠️ Technologies Used

- 🌐 **HTML5** – Provides the structure and content of the website.
- 🎨 **CSS3** – Handles styling and visual presentation.
- 🅱️ **Bootstrap 5** – Supports responsive layouts and interface components.
- 🐘 **PHP** – Supports server-side functionality and reusable website components.
- 🐙 **Git and GitHub** – Used for version control and project hosting.

## 🚀 Getting Started

### 📋 Prerequisites

To run the website locally, you will need:

- A web browser.
- A local development environment, such as XAMPP, if PHP is used.
- Git, if you want to clone the repository.

### ⚙️ Installation

1. Clone or download the repository from GitHub.
2. Place the project folder inside the `htdocs` directory if you are using XAMPP.
3. Start Apache through the XAMPP Control Panel.
4. Open your web browser and navigate to:

   `http://localhost/iCinema/`

*If the project is being developed using only HTML, CSS and Bootstrap, you can also open `index.html` directly in your browser. PHP pages require a PHP-enabled server.*
